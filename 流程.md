# 课题组资源库 —— Ubuntu完整部署方案

## 📋 环境信息确认

```
系统：Ubuntu
人数：≤30人 （轻量级，服务器压力很小）
权限：暂时开放，无需审核
资源：代码/小文件 （存储压力极小）
```

> 💡 **30人以内 + 小文件** = 配置非常简单，普通服务器完全够用

---

## 🗺️ 最终架构

```
your-domain.com/           → 导航主页
your-domain.com/jupyter/   → JupyterHub (Notebook教程)
your-domain.com/files/     → FileBrowser (资源下载)
your-domain.com/docs/      → MkDocs (可选，静态文档)

          全部通过 Nginx 统一入口 + HTTPS
```

## 🚀 开始部署

### 📌 第零步：系统初始化

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装基础工具
sudo apt install -y curl wget git nginx python3 python3-pip

# 安装certbot(HTTPS证书)
sudo apt install -y certbot python3-certbot-nginx

# 创建资源目录
sudo mkdir -p /data/resources
sudo chmod 755 /data/resources
```

### 📌 第一步：安装 Miniconda + JupyterHub

```bash
# 下载Miniconda
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh -O miniconda.sh

# 安装（一路回车/yes）
bash miniconda.sh -b -p /opt/conda

# 添加到环境变量
echo 'export PATH="/opt/conda/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

# 验证
conda --version
```

```bash
# 安装JupyterHub和JupyterLab
conda install -c conda-forge -y \
    jupyterhub \
    jupyterlab \
    notebook \
    ipykernel

# 验证安装
jupyterhub --version
```

```bash
# 创建JupyterHub配置目录
sudo mkdir -p /etc/jupyterhub
sudo mkdir -p /srv/jupyterhub

# 生成配置文件
cd /etc/jupyterhub
jupyterhub --generate-config

```

```python
# 编辑配置文件
# sudo nano /etc/jupyterhub/jupyterhub_config.py
# 找到对应行修改，或直接在文件末尾添加以下内容：

# 基本配置
c.JupyterHub.ip = '127.0.0.1'
c.JupyterHub.port = 8000

# 挂载路径（配合Nginx使用）
c.JupyterHub.base_url = '/jupyter/'

# Notebook存放目录
c.Spawner.notebook_dir = '/srv/jupyterhub/notebooks'

# 默认启动JupyterLab界面
c.Spawner.default_url = '/lab'

# 允许所有系统用户登录（课题组成员用Linux账号登录）
c.Authenticator.allow_all = True
```

```bash
# 创建Notebook目录
sudo mkdir -p /srv/jupyterhub/notebooks
sudo chmod 777 /srv/jupyterhub/notebooks

# 测试启动（Ctrl+C退出）
jupyterhub -f /etc/jupyterhub/jupyterhub_config.py
```

### 📌 第三步：安装 FileBrowser

```bash
# 一键安装
curl -fsSL https://raw.githubusercontent.com/filebrowser/get/master/get.sh | bash

# 初始化配置
filebrowser config init --database /etc/filebrowser/filebrowser.db

# 配置访问路径和根目录
filebrowser config set \
    --database /etc/filebrowser/filebrowser.db \
    --address 127.0.0.1 \
    --port 8080 \
    --root /data/resources \
    --baseurl /files

# 创建管理员账号（修改密码！）
filebrowser users add admin 你的密码 \
    --database /etc/filebrowser/filebrowser.db \
    --perm.admin

# 测试启动（Ctrl+C退出）
filebrowser --database /etc/filebrowser/filebrowser.db
```

```bash
# 创建filebrowser配置目录
sudo mkdir -p /etc/filebrowser
```

### 📌 第四步：配置 Nginx

```bash
# 创建配置文件
sudo nano /etc/nginx/sites-available/lab-resources
```

```nginx
# /etc/nginx/sites-available/lab-resources

server {
    listen 80;
    server_name your-domain.com;  # ← 替换成你的DDNS域名

    # ============ 导航主页 ============
    location / {
        root /srv/www/lab-home;
        index index.html;
        try_files $uri $uri/ =404;
    }

    # ============ JupyterHub ============
    location /jupyter/ {
        proxy_pass http://127.0.0.1:8000;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket支持（Jupyter必须）
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        # 超时设置（防止长时间运行的notebook断连）
        proxy_read_timeout 86400;
    }

    # JupyterHub API
    location /jupyter/hub/api {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_buffering off;
    }

    # ============ FileBrowser 资源库 ============
    location /files/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;

        # 支持大文件上传（代码文件用不到，保险起见设置）
        client_max_body_size 500M;
    }
}
```

```bash
# 创建主页目录
sudo mkdir -p /srv/www/lab-home

# 启用配置（删除默认配置）
sudo rm -f /etc/nginx/sites-enabled/default
sudo ln -s /etc/nginx/sites-available/lab-resources /etc/nginx/sites-enabled/

# 测试配置语法
sudo nginx -t

# 启动Nginx
sudo systemctl restart nginx
```

### 📌 第六步：配置 Systemd 开机自启

```bash
# ① JupyterHub 服务
sudo nano /etc/systemd/system/jupyterhub.service
```

```ini
[Unit]
Description=JupyterHub
After=network.target

[Service]
User=root
Environment="PATH=/opt/conda/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin"
ExecStart=/opt/conda/bin/jupyterhub -f /etc/jupyterhub/jupyterhub_config.py
WorkingDirectory=/etc/jupyterhub
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# ② FileBrowser 服务
sudo nano /etc/systemd/system/filebrowser.service
```

```ini
[Unit]
Description=FileBrowser
After=network.target

[Service]
User=root
ExecStart=/usr/local/bin/filebrowser --database /etc/filebrowser/filebrowser.db
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# 启用并启动所有服务
sudo systemctl daemon-reload
sudo systemctl enable jupyterhub filebrowser nginx
sudo systemctl start jupyterhub filebrowser

# 查看运行状态
sudo systemctl status jupyterhub
sudo systemctl status filebrowser
sudo systemctl status nginx
```

## ⚠️ 注意事项

| 事项     | 说明                                            |
| -------- | ----------------------------------------------- |
| 域名替换 | 所有`your-domain.com`替换为你的实际DDNS域名     |
| 密码安全 | FileBrowser管理员密码务必设置强密码             |
| 定期备份 | `/data/resources` 和 `/srv/jupyterhub` 定期备份 |
| DDNS更新 | 确认DDNS客户端在服务器上持续运行                |
