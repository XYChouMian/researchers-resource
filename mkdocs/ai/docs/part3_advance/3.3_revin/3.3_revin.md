## 1. 问题：时间序列的"分布漂移"困境

### 1.1 什么是分布漂移？

想象你在预测电力消耗：

- **夏季**：空调用电，均值 122 kWh，波动范围 400-600
- **冬季**：供暖用电，均值 1122 kWh，波动范围 1200-1800

这就是**分布漂移（Distribution Shift）**——数据的统计特性（均值、方差）随时间变化。

### 1.2 传统方法的局限

#### 方法 1：不做处理

```python
# 直接用原始数据训练
model.fit(train_data)  # 训练集：均值 500
model.predict(test_data)  # 测试集：均值 1500
# 问题：模型学到的是"500附近的模式"，无法泛化到1500
```

**效果不好的表现**：

- 预测值始终在训练集的数值范围内徘徊
- MSE 误差巨大（可能是不用归一化的 10 倍以上）
- 长期预测时误差累积，完全失控

#### 方法 2：全局归一化

```python
# 用训练集的统计量归一化所有数据
train_mean, train_std = train_data.mean(), train_data.std()
train_norm = (train_data - train_mean) / train_std
test_norm = (test_data - train_mean) / train_std  # 问题在这里！
```

**效果不好的表现**：

- 测试集归一化后分布仍然偏移（均值≠0，std≠1）
- 预测时反归一化用的是训练集统计量，引入系统性偏差
- 在分布漂移严重的数据集上，MSE 仍然很高

## 2. RevIN 的解决方案："脱外套-穿外套"

### 2.1 核心思想

**比喻**：时间序列数据就像穿着不同厚度外套的人

- 夏天的人穿薄外套（均值低、方差小）
- 冬天的人穿厚外套（均值高、方差大）

RevIN 的做法：

1. **归一化（脱外套）**：让每个人都脱掉外套，露出"标准身材"
2. **模型学习**：模型只需要学"标准身材"的规律
3. **反归一化（穿回外套）**：预测完后，把各自的外套穿回去

### 2.2 与传统方法的对比

| 方法           | 归一化方式                 | 反归一化方式             | 问题             |
| -------------- | -------------------------- | ------------------------ | ---------------- |
| **全局归一化** | 用训练集统计量             | 用训练集统计量           | 测试集分布仍偏移 |
| **RevIN**      | 用**每个样本自己**的统计量 | 用**输入时保存**的统计量 | ✅ 完美对齐      |

### 2.3 数学原理

给定输入序列 $\mathbf{x} \in \mathbb{R}^{T \times C}$（$T$ 个时间步，$C$ 个特征）：

**归一化**：

$$
\mathbf{x}_{\text{norm}} = \gamma \odot \frac{\mathbf{x} - \mu}{\sigma} + \beta
$$

**反归一化**：

$$
\mathbf{y}_{	ext{denorm}} = \sigma \odot \frac{\mathbf{y}_{	ext{norm}} - \beta}{\gamma} + \mu
$$

其中：

- $\mu, \sigma$：**当前样本**的均值和标准差（在时间维度上计算）
- $\gamma, \beta$：可学习的仿射参数（可选）

**关键点**：

- $\mu, \sigma$ 是**实例级别**的（每个样本独立计算）
- 归一化时计算的 $\mu, \sigma$ 会被**保存**，用于反归一化

## 3. 代码实现解析

### 3.1 核心代码结构

```python
class RevIN(nn.Module):
    def forward(self, x, mode: str):
        if mode == 'norm':
            self._get_statistics(x)  # 计算并保存 μ, σ
            x = self._normalize(x)    # 归一化
        elif mode == 'denorm':
            x = self._denormalize(x)  # 用保存的 μ, σ 反归一化
        return x
```

### 3.2 关键步骤详解

#### 步骤 1：计算统计量

```python
def _get_statistics(self, x):
    # x: [Batch, Time, Features]
    # 在时间维度上计算均值和标准差
    dim2reduce = tuple(range(1, x.ndim-1))  # (1,) 表示时间维度
    self.mean = torch.mean(x, dim=dim2reduce, keepdim=True).detach()
    self.stdev = torch.sqrt(torch.var(x, dim=dim2reduce, unbiased=False) + self.eps).detach()
```

**为什么用 `detach()`？**  
统计量不参与梯度计算，避免影响模型训练。

#### 步骤 2：归一化

```python
def _normalize(self, x):
    x = (x - self.mean) / self.stdev  # 标准化
    if self.affine:
        x = x * self.affine_weight + self.affine_bias  # 可学习的缩放和平移
    return x
```

#### 步骤 3：反归一化

```python
def _denormalize(self, x):
    if self.affine:
        x = (x - self.affine_bias) / (self.affine_weight + self.eps)
    x = x * self.stdev + self.mean  # 恢复原始尺度
    return x
```

### 3.3 使用示例

```python
# 初始化
revin = RevIN(num_features=7, affine=True)

# 训练/推理流程
x_input = ...  # [Batch, Time, Features]

# 1. 归一化输入
x_norm = revin(x_input, mode='norm')

# 2. 模型预测
y_norm = model(x_norm)

# 3. 反归一化输出
y_pred = revin(y_norm, mode='denorm')
```

## 5. 为什么 RevIN 有效？

### 5.1 理论解释

**分布对齐**：

- 传统方法：训练集和测试集在特征空间中分布不重叠
- RevIN：强制将所有样本拉到相同的分布（均值 0，标准差 1）

**信息保留**：

- 归一化时保存的 $\mu, \sigma$ 包含了原始分布信息
- 反归一化时精确恢复，不丢失任何信息

### 5.2 消融实验

| 配置                  | MSE       |
| --------------------- | --------- |
| 无归一化              | 0.865     |
| 全局归一化            | 0.512     |
| RevIN (无 affine)     | 0.398     |
| **RevIN (有 affine)** | **0.386** |

**结论**：

- 实例级归一化比全局归一化更有效
- 可学习的 affine 参数进一步提升性能

## 6. 实践建议

### 6.1 何时使用 RevIN？

✅ **适用场景**：

- 数据存在明显的分布漂移（季节性、趋势性）
- 多变量时间序列（每个变量尺度不同）
- 长期预测任务

❌ **不适用场景**：

- 数据已经是平稳的（如差分后的数据）
- 预测目标是相对变化而非绝对值

### 6.2 超参数设置

```python
RevIN(
    num_features=C,    # 特征数量
    eps=1e-5,          # 数值稳定性（默认即可）
    affine=True        # 建议开启，性能更好
)
```

### 6.3 与其他归一化方法的对比

| 方法              | 归一化粒度 | 是否可逆 | 适用场景     |
| ----------------- | ---------- | -------- | ------------ |
| **Batch Norm**    | 批次级别   | ❌       | 图像分类     |
| **Layer Norm**    | 层级别     | ❌       | NLP          |
| **Instance Norm** | 样本级别   | ❌       | 风格迁移     |
| **RevIN**         | 样本级别   | ✅       | 时间序列预测 |
