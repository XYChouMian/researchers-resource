### **高斯分布 score 的解析解**

#### **第一步：高斯分布的对数概率**

我们熟悉的一维高斯分布的概率密度函数为：

$$p(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x - \mu)^2}{2\sigma^2}\right)$$

写为契合本论文的向量形式为：

$$p(\mathbf{x}) = \frac{1}{(2\pi)^{d/2}|\boldsymbol{\Sigma}|^{1/2}} \exp\left(-\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu})^\top\boldsymbol{\Sigma}^{-1}(\mathbf{x} - \boldsymbol{\mu})\right)$$

两边取对数：

$$\log p(\mathbf{x}) = -\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu})^\top\boldsymbol{\Sigma}^{-1}(\mathbf{x} - \boldsymbol{\mu}) \underbrace{- \frac{d}{2}\log(2\pi) - \frac{1}{2}\log|\boldsymbol{\Sigma}|}_{\text{const（与 } \mathbf{x} \text{ 无关）}}$$

因此：

$$\log p(\mathbf{x}) = -\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu})^\top\boldsymbol{\Sigma}^{-1}(\mathbf{x} - \boldsymbol{\mu}) + \text{const}$$

**为什么取对数？** 因为指数函数里的内容对求导更方便，对数把 $\exp$ 去掉了。常数项与 $\mathbf{x}$ 无关，求导后直接消失。

#### **第二步：对 $\mathbf{x}$ 求梯度（score）**

这一步是关键。我们要对 $\mathbf{x}$ 求梯度，即 $\nabla_{\mathbf{x}} \log p(\mathbf{x})$。

**符号说明**：$\nabla_{\mathbf{x}}$ 表示对向量 $\mathbf{x}$ 的每个分量分别求偏导数，结果是一个与 $\mathbf{x}$ 同维度的向量。

先看一维的类比理解：若 $f(x) = -\frac{1}{2\sigma^2}(x - \mu)^2$，则 $\frac{df}{dx} = -\frac{1}{\sigma^2}(x - \mu)$

推广到多维向量情形：

$$\nabla_{\mathbf{x}} \left[ -\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu})^\top\boldsymbol{\Sigma}^{-1}(\mathbf{x} - \boldsymbol{\mu}) \right] = -\boldsymbol{\Sigma}^{-1}(\mathbf{x} - \boldsymbol{\mu})$$

这是多元微积分中的标准结论：二次型 $\mathbf{a}^\top \mathbf{M} \mathbf{a}$ 对 $\mathbf{a}$ 求导结果为 $2\mathbf{M}\mathbf{a}$，当 $\mathbf{M}$ 对称时；加上前面的 $-\frac{1}{2}$ 后系数变为 $1$。因此：

$$\nabla_{\mathbf{x}}\log p(\mathbf{x}) = -\boldsymbol{\Sigma}^{-1}(\mathbf{x} - \boldsymbol{\mu})$$

**物理直觉**：这个梯度指向均值 $\boldsymbol{\mu}$，告诉我们"往哪个方向走概率密度会增大"——答案就是向分布中心靠近。

#### **第三步：应用到转移核**

我们的转移核是：

$$p_{0t}(\mathbf{x}(t)|\mathbf{x}(0)) = \mathcal{N}(\mathbf{x}(t);\ \underbrace{\alpha(t)\mathbf{x}(0)}_{\boldsymbol{\mu}},\ \underbrace{\sigma^2(t)\mathbf{I}}_{\boldsymbol{\Sigma}})$$

对应关系：

- 随机变量：$\mathbf{x} \leftrightarrow \mathbf{x}(t)$
- 均值：$\boldsymbol{\mu} \leftrightarrow \alpha(t)\mathbf{x}(0)$
- 协方差矩阵：$\boldsymbol{\Sigma} \leftrightarrow \sigma^2(t)\mathbf{I}$

其中 $\boldsymbol{\Sigma}^{-1} = (\sigma^2(t)\mathbf{I})^{-1} = \frac{1}{\sigma^2(t)}\mathbf{I}$（单位矩阵的逆还是单位矩阵，只需除以标量 $\sigma^2(t)$）

直接代入第二步的结论：

$$\nabla_{\mathbf{x}(t)}\log p_{0t}(\mathbf{x}(t)|\mathbf{x}(0)) = -\frac{1}{\sigma^2(t)}\mathbf{I} \cdot (\mathbf{x}(t) - \alpha(t)\mathbf{x}(0)) = -\frac{\mathbf{x}(t) - \alpha(t)\mathbf{x}(0)}{\sigma^2(t)}$$

#### **第四步：代入重参数化**

由重参数化技巧 $\mathbf{x}(t) = \alpha(t)\mathbf{x}(0) + \sigma(t)\boldsymbol{\epsilon}$，代入分子：

$$\mathbf{x}(t) - \alpha(t)\mathbf{x}(0) = \alpha(t)\mathbf{x}(0) + \sigma(t)\boldsymbol{\epsilon} - \alpha(t)\mathbf{x}(0) = \sigma(t)\boldsymbol{\epsilon}$$

因此：

$$\nabla_{\mathbf{x}(t)}\log p_{0t}(\mathbf{x}(t)|\mathbf{x}(0)) = -\frac{\sigma(t)\boldsymbol{\epsilon}}{\sigma^2(t)} = -\frac{\boldsymbol{\epsilon}}{\sigma(t)}$$

#### **结果的物理意义**

$$\boxed{\nabla_{\mathbf{x}(t)}\log p_{0t}(\mathbf{x}(t)|\mathbf{x}(0)) = -\frac{\boldsymbol{\epsilon}}{\sigma(t)}}$$

这个结果非常优美：

- **$\boldsymbol{\epsilon}$** 是我们加入的那一份噪声（已知量）
- **$\sigma(t)$** 是噪声的标准差（已知量）
- **score** 的方向恰好是噪声的**反方向**（$-\boldsymbol{\epsilon}$）

直觉上完全合理：

> score 指向概率密度增大的方向，即"去噪"的方向。  
> 而加噪方向是 $+\boldsymbol{\epsilon}$，去噪方向自然是 $-\boldsymbol{\epsilon}$。

**这就是为什么训练扩散模型等价于训练网络预测噪声**：

$$s_\theta(\mathbf{x}(t), t) \approx \nabla_{\mathbf{x}(t)}\log p(\mathbf{x}(t)) = -\frac{\boldsymbol{\epsilon}}{\sigma(t)}$$

网络预测 score，等价于预测 $-\boldsymbol{\epsilon}/\sigma(t)$，等价于预测加入的噪声 $\boldsymbol{\epsilon}$（只差一个已知的标量因子 $\sigma(t)$）。
