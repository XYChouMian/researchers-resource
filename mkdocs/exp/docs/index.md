## 🌊 实验设备指南

### PIV 测速技术

PIV（Particle Image Velocimetry）是一种非侵入式的流场测速技术，通过激光照亮流场中的示踪粒子，利用跨帧互相关算法计算粒子位移，从而获得流场的速度分布。

- **测速技术原理**：包含粒子、激光与跨帧互相关原理
- **实验操作手册**：设备安全须知与标准操作流程

### 热线风速仪技术

热线风速仪基于热传导原理，通过加热细丝并测量其热量损失来推算流体速度，是测量复杂流场速度的重要工具。

- **原理**：传热学与桥路解析
- **设备标定与实操**：设备标定方法与操作指南
