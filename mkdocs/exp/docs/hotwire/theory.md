# 热线风速仪原理：传热学与桥路解析

## 1. 基本概念

热线风速仪（Hot-Wire Anemometer, HWA）是一种利用发热金属丝与流体之间的对流换热关系来测量流速的仪器。

其核心敏感元件是一根很细的金属丝，称为热线。热线通电后由于焦耳效应发热，当流体流过热线时，会带走热量。

流速越大，对流换热越强，热线的散热越快。通过测量热线的电压、电流或电阻变化，即可反推出流体速度。

---

## 2. 基本物理过程

热线风速仪的基本过程可以表示为：

```text
流速变化
   ↓
对流换热强度变化
   ↓
热线温度变化或所需加热功率变化
   ↓
热线电阻、电压或电流变化
   ↓
反推出流速
```

热线的主要热量来源是电加热：

\[
P_e = I^2 R_w
\]

其中：

| 符号    | 含义           |
| ------- | -------------- |
| \(P_e\) | 电加热功率     |
| \(I\)   | 通过热线的电流 |
| \(R_w\) | 热线电阻       |

热线的主要热量损失包括：

1. 对流换热损失
2. 向支架的导热损失
3. 辐射换热损失

在一般气体测速条件下，辐射换热通常较小；若热线足够细且长度合适，端部导热也可通过标定吸收。因此，热线风速仪的核心分析通常集中在对流换热上。

---

# 一、传热学解析

## 3. 热线能量平衡方程

热线的瞬态能量平衡可写为：

\[
m_w c_w \frac{dT_w}{dt}
=
I^2 R_w
-
Q_c
-
Q_k
-
Q_r
\]

其中：

| 符号    | 含义             |
| ------- | ---------------- |
| \(m_w\) | 热线质量         |
| \(c_w\) | 热线比热容       |
| \(T_w\) | 热线温度         |
| \(I\)   | 热线电流         |
| \(R_w\) | 热线电阻         |
| \(Q_c\) | 对流换热量       |
| \(Q_k\) | 端部支架导热损失 |
| \(Q_r\) | 辐射换热损失     |

稳态时：

\[
\frac{dT_w}{dt}=0
\]

因此有：

\[
I^2R_w = Q_c + Q_k + Q_r
\]

若忽略导热和辐射，得到简化形式：

\[
I^2R_w = Q_c
\]

---

## 4. 对流换热关系

热线可近似看作横置于流场中的细圆柱体。热线与流体之间的对流换热量为：

\[
Q_c = h A_w (T_w - T_f)
\]

其中：

| 符号    | 含义         |
| ------- | ------------ |
| \(h\)   | 对流换热系数 |
| \(A_w\) | 热线表面积   |
| \(T_w\) | 热线温度     |
| \(T_f\) | 流体温度     |

热线表面积近似为：

\[
A_w = \pi d l
\]

其中：

| 符号  | 含义         |
| ----- | ------------ |
| \(d\) | 热线直径     |
| \(l\) | 热线有效长度 |

因此：

\[
I^2R_w = h \pi d l (T_w - T_f)
\]

该式说明：在热线温度一定时，电加热功率主要由对流换热系数 \(h\) 决定。

而 \(h\) 与流体速度 \(U\) 有关，这就是热线风速仪能够测速的传热学基础。

---

## 5. 努塞尔数与雷诺数

对于圆柱绕流问题，常用无量纲数描述换热规律。

努塞尔数定义为：

\[
Nu = \frac{h d}{k_f}
\]

雷诺数定义为：

\[
Re = \frac{\rho U d}{\mu}
\]

其中：

| 符号     | 含义         |
| -------- | ------------ |
| \(Nu\)   | 努塞尔数     |
| \(Re\)   | 雷诺数       |
| \(k_f\)  | 流体导热系数 |
| \(\rho\) | 流体密度     |
| \(U\)    | 流速         |
| \(d\)    | 热线直径     |
| \(\mu\)  | 流体动力黏度 |

热线风速仪中常用经验关系：

\[
Nu = A + B Re^n
\]

其中 \(A\)、\(B\)、\(n\) 为经验常数。

由努塞尔数定义可得：

\[
h = \frac{k_f}{d}Nu
\]

代入经验关系：

\[
h =
\frac{k_f}{d}
\left[
A + B
\left(
\frac{\rho U d}{\mu}
\right)^n
\right]
\]

因此，对流换热系数可以表示为流速的函数：

\[
h = C_1 + C_2 U^n
\]

---

## 6. King 定律

将对流换热关系代入稳态能量平衡：

\[
I^2R_w = hA_w(T_w-T_f)
\]

如果热线工作温度保持不变，即 \(T_w-T_f\) 近似恒定，则有：

\[
I^2R_w = A_1 + B_1 U^n
\]

对于恒温热线风速仪，热线电阻 \(R_w\) 保持恒定，热线两端电压为：

\[
E_w = IR_w
\]

因此：

\[
E_w^2 = I^2 R_w^2
\]

由于 \(R_w\) 恒定，所以：

\[
E_w^2 = A + B U^n
\]

这就是热线风速仪常用的 King 定律：

\[
E^2 = A + B U^n
\]

其中：

| 符号      | 含义                               |
| --------- | ---------------------------------- |
| \(E\)     | 热线输出电压或与热线功率相关的电压 |
| \(U\)     | 流体速度                           |
| \(A,B,n\) | 标定常数                           |

工程上常取：

\[
n \approx 0.45 \sim 0.5
\]

若取 \(n=0.5\)，则：

\[
E^2 = A + B\sqrt{U}
\]

更通用的反算流速公式为：

\[
U =
\left(
\frac{E^2-A}{B}
\right)^{1/n}
\]

---

## 7. 热线电阻与温度关系

热线金属材料的电阻随温度升高而增大。在线性近似下：

\[
R_w = R_0[1+\alpha(T_w-T_0)]
\]

其中：

| 符号       | 含义                          |
| ---------- | ----------------------------- |
| \(R_w\)    | 工作温度下的热线电阻          |
| \(R_0\)    | 参考温度 \(T_0\) 下的热线电阻 |
| \(\alpha\) | 电阻温度系数                  |
| \(T_w\)    | 热线温度                      |
| \(T_0\)    | 参考温度                      |

由此可得热线温度：

\[
T_w =
T_0 +
\frac{R_w/R_0 - 1}{\alpha}
\]

因此，只要控制或测量热线电阻，就可以间接控制或测量热线温度。

# 二、工作方式

## 8. 恒流式热线风速仪

恒流式热线风速仪（Constant Current Anemometer, CCA）保持热线电流 \(I\) 近似恒定。

当流速增大时：

```text
流速增大
   ↓
对流换热增强
   ↓
热线温度下降
   ↓
热线电阻减小
   ↓
热线电压减小
```

热线电压为：

\[
E_w = IR_w
\]

由于 \(I\) 恒定，所以：

\[
E_w \propto R_w
\]

因此可以通过热线电压变化反映流速变化。

### 恒流式特点

优点：

- 电路简单
- 易于实现

缺点：

- 热线温度随流速变化
- 动态响应较慢
- 频率响应较低
- 温度补偿较复杂

---

## 9. 恒温式热线风速仪

恒温式热线风速仪（Constant Temperature Anemometer, CTA）通过反馈控制，使热线电阻 \(R_w\) 保持恒定。

由于：

\[
R_w = R_0[1+\alpha(T_w-T_0)]
\]

所以当 \(R_w\) 恒定时，热线温度 \(T_w\) 也近似恒定。

当流速增大时：

```text
流速增大
   ↓
热线散热增强
   ↓
热线温度趋于下降
   ↓
热线电阻趋于减小
   ↓
电桥失衡
   ↓
反馈电路增大加热电流
   ↓
热线温度恢复设定值
```

因此，恒温热线风速仪测量的本质是：

> 为维持热线温度恒定所需的电加热功率。

在恒温条件下：

\[
R_w = \text{constant}
\]

电加热功率为：

\[
P_e = I^2R_w = \frac{E_w^2}{R_w}
\]

由于 \(R_w\) 恒定：

\[
E_w^2 \propto P_e
\]

结合 King 定律：

\[
E_w^2 = A + BU^n
\]

因此，恒温式热线风速仪特别适合用于高速动态测量和湍流脉动测量。

---

# 三、惠斯通桥路解析

## 10. 恒温热线风速仪桥路结构

恒温热线风速仪通常使用惠斯通电桥检测热线电阻变化。

典型桥路如下：

```text
              Vs
              │
        ┌─────┴─────┐
        │           │
        R1          R2
        │           │
        │           │
        o Va     Vb o
        │           │
        Rw          R3
        │           │
        └─────┬─────┘
              │
             GND
```

其中：

| 元件            | 含义             |
| --------------- | ---------------- |
| \(R_w\)         | 热线电阻         |
| \(R_1,R_2,R_3\) | 桥臂电阻         |
| \(V_s\)         | 桥路供电电压     |
| \(V_a,V_b\)     | 两个桥臂中点电压 |

桥路输出为：

\[
V_o = V_a - V_b
\]

---

## 11. 桥路中点电压

左侧桥臂由 \(R_1\) 和 \(R_w\) 串联组成，因此中点电压为：

\[
V_a =
V_s
\frac{R_w}{R_1+R_w}
\]

右侧桥臂由 \(R_2\) 和 \(R_3\) 串联组成，因此中点电压为：

\[
V_b =
V_s
\frac{R_3}{R_2+R_3}
\]

桥路输出为：

\[
V_o =
V_s
\left[
\frac{R_w}{R_1+R_w}
-
\frac{R_3}{R_2+R_3}
\right]
\]

当热线电阻变化时，\(V_a\) 变化，电桥产生不平衡输出。

---

## 12. 桥路平衡条件

桥路平衡时：

\[
V_a = V_b
\]

因此：

\[
\frac{R_w}{R_1+R_w}
=
\frac{R_3}{R_2+R_3}
\]

交叉相乘：

\[
R_w(R_2+R_3)=R_3(R_1+R_w)
\]

展开：

\[
R_wR_2+R_wR_3=R_1R_3+R_wR_3
\]

化简得：

\[
R_wR_2=R_1R_3
\]

所以平衡条件为：

\[
R_w=\frac{R_1R_3}{R_2}
\]

或写成比例形式：

\[
\frac{R_1}{R_2}=\frac{R_w}{R_3}
\]

该平衡电阻就是恒温热线的目标工作电阻。

---

## 13. 过热比

恒温热线风速仪常用过热比描述热线工作点。

过热比定义为：

\[
a =
\frac{R_w-R_f}{R_f}
\]

其中：

| 符号    |          含义          |
| ------- | :--------------------: |
| \(a\)   |         过热比         |
| \(R_w\) |  热线工作温度下的电阻  |
| \(R_f\) | 流体温度下热线冷态电阻 |

因此：

\[
R_w = R_f(1+a)
\]

根据电阻温度关系：

\[
R_w = R_f[1+\alpha(T_w-T_f)]
\]

可得：

\[
a = \alpha(T_w-T_f)
\]

所以热线相对流体的温升为：

\[
T_w-T_f=\frac{a}{\alpha}
\]

常见过热比范围为：

\[
a = 0.5 \sim 2.0
\]

对于气体测量，过热比通常较高；对于液体测量，由于换热强、热线更易烧毁，过热比通常较低。

---

## 14. 由桥路设定热线工作温度

由桥路平衡条件：

\[
R_w=\frac{R_1R_3}{R_2}
\]

如果希望设定某一过热比 \(a\)，则热线目标工作电阻为：

\[
R_w=R_f(1+a)
\]

因此桥路参数应满足：

\[
\frac{R_1R_3}{R_2}=R_f(1+a)
\]

这说明，通过选择 \(R_1\)、\(R_2\)、\(R_3\) 的比例，可以设定热线的工作温度。

---

## 15. 恒温反馈控制过程

在恒温热线风速仪中，惠斯通电桥通常与高增益放大器组成闭环控制系统。

反馈过程如下：

```text
热线电阻偏离设定值
   ↓
电桥产生不平衡电压
   ↓
放大器检测误差信号
   ↓
调节桥路供电电压或热线电流
   ↓
热线加热功率改变
   ↓
热线电阻恢复设定值
```

### 流速增大时

\[
U \uparrow
\]

对流换热增强：

\[
Q_c \uparrow
\]

热线温度趋于下降：

\[
T_w \downarrow
\]

热线电阻趋于减小：

\[
R_w \downarrow
\]

电桥失衡，反馈放大器增大输出，使热线电流增大：

\[
I \uparrow
\]

电加热功率增大：

\[
P_e=I^2R_w \uparrow
\]

最终：

\[
R_w \rightarrow R_{set}
\]

输出电压升高。

### 流速减小时

\[
U \downarrow
\]

对流换热减弱：

\[
Q_c \downarrow
\]

热线温度趋于升高：

\[
T_w \uparrow
\]

热线电阻趋于增大：

\[
R_w \uparrow
\]

电桥失衡，反馈放大器降低输出，使热线电流减小：

\[
I \downarrow
\]

电加热功率减小：

\[
P_e=I^2R_w \downarrow
\]

最终：

\[
R_w \rightarrow R_{set}
\]

输出电压降低。

---

## 16. 桥路输出与流速关系

恒温工作时：

\[
R_w=R_{set}
\]

热线电加热功率为：

\[
P_e = I^2R_w
\]

热线两端电压为：

\[
E_w = IR_w
\]

所以：

\[
P_e = \frac{E_w^2}{R_w}
\]

由于 \(R_w\) 为常数：

\[
P_e \propto E_w^2
\]

而由传热学关系可得：

\[
P_e = A + BU^n
\]

因此：

\[
E_w^2 = A' + B'U^n
\]

通常简写为：

\[
E^2 = A + BU^n
\]

反算流速为：

\[
U=
\left(
\frac{E^2-A}{B}
\right)^{1/n}
\]

---

# 四、动态特性分析

## 17. 热线热惯性

热线具有有限热容，因此温度变化不是瞬时完成的。

热线瞬态能量方程为：

\[
m_wc_w\frac{dT_w}{dt}
=
I^2R_w
-
hA_w(T_w-T_f)
\]

在小扰动条件下，可以近似为一阶系统：

\[
\tau \frac{d\theta}{dt}+\theta=K u
\]

其中：

| 符号       | 含义         |
| ---------- | ------------ |
| \(\tau\)   | 热时间常数   |
| \(\theta\) | 热线温度扰动 |
| \(u\)      | 流速扰动     |
| \(K\)      | 静态增益     |

热时间常数近似为：

\[
\tau =
\frac{m_wc_w}{hA_w}
\]

流速越大，换热系数 \(h\) 越大，因此：

\[
\tau \downarrow
\]

热线响应更快。

---

## 18. 恒温模式的动态优势

恒流模式下，热线温度需要通过自身热惯性变化来响应流速变化，因此频率响应较低。

恒温模式下，反馈系统快速调节电流，使热线温度几乎不变，而输出电压直接反映维持恒温所需的功率变化。

因此恒温热线风速仪具有：

- 更高的频率响应
- 更好的动态性能
- 更适合测量湍流脉动速度
- 更好的线性化和标定便利性

---

# 五、标定与实际使用

## 19. 标定关系

实际使用中，热线风速仪通常不直接由理论公式计算流速，而是通过实验标定得到电压与流速之间的关系。

常用标定式为：

\[
E^2=A+BU^n
\]

其中 \(A\)、\(B\)、\(n\) 由标定实验拟合得到。

若取 \(n=0.5\)，则：

\[
E^2=A+B\sqrt{U}
\]

反算：

\[
U=
\left(
\frac{E^2-A}{B}
\right)^2
\]

更一般地：

\[
U=
\left(
\frac{E^2-A}{B}
\right)^{1/n}
\]

---

## 20. 温度补偿

热线散热与流体温度有关：

\[
Q_c=hA_w(T_w-T_f)
\]

如果环境温度 \(T_f\) 变化，即使流速不变，热线输出也会变化。

因此，实际使用中需要进行温度补偿。

当流体温度升高时：

- 冷态电阻 \(R_f\) 增大
- 过热比可能变化
- \(T_w-T_f\) 改变
- 标定系数 \(A\)、\(B\)、\(n\) 发生偏移

常见处理方法包括：

1. 在恒定环境温度下标定和使用
2. 使用温度传感器测量流体温度并修正
3. 建立不同温度下的标定曲线
4. 使用恒过热比控制策略

---

# 七、总结

热线风速仪的核心可以概括为：

```text
流速 U
   ↓
对流换热系数 h
   ↓
热线散热功率 Qc
   ↓
维持热线温度所需电功率 Pe
   ↓
输出电压 E
```

传热学给出了流速与散热功率之间的关系：

\[
P_e=A+BU^n
\]

桥路与反馈电路将热线电阻控制在设定值，并把维持恒温所需的功率转换为电压输出：

\[
E^2=A+BU^n
\]

因此，热线风速仪本质上是一种将流速引起的对流换热变化转换为电压信号变化的热式测速仪。
